# Security policy

Please report a security problem privately, not in a public issue: use
[Report a vulnerability](https://github.com/pctablet505/porchlamp-engine/security/advisories/new)
on this repository's Security tab. You will get a reply from a person within
14 days.

A security problem is anything that could let someone run code, read a secret
or change what porchlamp.org shows, in:

- the engine and its collectors (`porchlamp/`, `scripts/`);
- the site's pages and scripts (`web/`);
- the workflows that test and publish (`.github/workflows/`);
- the Android collector (`phone/`).

A ranking you disagree with, or a record that looks wrong, is not a security
problem: open a public issue as [CONTRIBUTING.md](CONTRIBUTING.md) describes.

Only the latest commit on `main` is supported.
